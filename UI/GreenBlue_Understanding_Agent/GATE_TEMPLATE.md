## 1. 한 문장 요약

> 이번에는 ___을 구현했고, 실제 ___까지 확인했으며, ___은 아직 미완료이다.

## 2. 쉬운 설명 (비전공자 1분)

문제 → 해결방식 → 얻는 결과. 비유 1개.

## 3. 왜 필요한가? 이론적 배경

핵심 개념 3~5개, 선택 이유, 대안 1개, 한계. 확인된 경우만 수식/문헌 인용.

## 4. 시스템 구조도

```mermaid
flowchart LR
  A[입력 데이터] --> B[품질 검증]
  B --> C[Agent / 분석 서비스]
  C --> D[Orchestrator 결과 등록]
  D --> E[SDSS 지도 및 리포트]
```

|---|---|---|---|---|
| 예: 데이터 수집 | `경로를 직접 확인` | AOI·기간 | Scene metadata | 로그 파일 |

## 6. 입력 → 처리 → 출력

- 입력 데이터, 데이터 버전, CRS, 해상도, 단위, 시간 기준
- 처리 로직, 실패·차단 조건
- 결과 형태, 결과 참조 ID, 승인/품질 상태
