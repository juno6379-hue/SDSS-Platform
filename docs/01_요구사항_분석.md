## 2. 기존 자산과 실행환경 조사

시작 시 작업 폴더가 비어 있었고 Git 저장소, 기존 API/DB, 재사용 가능한 소스, 기존 프런트엔드가 없었다. 따라서 기존 정상 기능을 삭제하는 작업 없이 신규 프로젝트를 구성했다. Python 3.11.9, Node/npm, Docker 실행파일이 존재한다. PyTorch는 CPU 빌드이며 CUDA 사용 불가이다. `nvidia-smi` 명령은 없었다. 물리 GPU가 전혀 없다고 단정하지 않으며 현재 PyTorch 경로에서 GPU를 사용할 수 없음을 의미한다.

## 3. 원문 요구와 구현 선택의 구분

TECH-4 §2.3.2는 기존 토지피복도, 다중시기 위성영상, 지수와 RF/SVM/XGBoost 또는 동등한 분류기법을 제시한다. U-Net, Dynamic World 0.8, 256 패치, 70/15/15, FastAPI/React/MLflow는 사용자 마스터 지시에 따른 상세 구현 선택이다. 제안서가 특정 제품을 의무화했다고 해석하지 않는다. TECH-4의 3D, 공간 데이터큐브, RBAC, SRGI 2013, 기관연계·엣지 기능은 이번 LCLUC 우선 실증보다 넓으며 후속 범위로 유지한다.

## 5. 부족한 자료와 의사결정

공식 AOI/행정경계, RDTR/RTRW, KLHK 참조라벨, SRGI2013 적용 규칙, 기관 API 명세, 독립 시험참조, Earth Engine 인증/프로젝트가 필요하다. 공개 AOI 사각형은 연구 후보이며 발주처 승인 경계가 아니다. 실제 B04 64×64 검증용 부분 GeoTIFF 1개를 확보했고 충분한 학습자료 목표는 미충족이다. 사용자 추가 지시로 2020~2025×3지역 연차수집을 계획한다. 모의 응답과 합성 래스터를 실자료로 계산하지 않으며 이후 확보량은 docs10 및 수집보고서로 갱신한다.
