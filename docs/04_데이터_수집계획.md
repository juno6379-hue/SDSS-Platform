# 04. 데이터 수집계획과 충분성 기준

## 1. 수집 목표

기능 점검용 64×64 한 밴드 샘플은 접속·픽셀읽기 검증자료이다. 모델 학습량 확보와 구분한다. 사용자 2026-10-16 첨부화면 지시에 따라 실증 목표를 **First Group 6개 주 × 2020~2025년 연차별 시계열, 최소36개 주-연도 조합**으로 변경한다. Sentinel-2 L2A 다중밴드와 같은 시기/근접시기 라벨을 연결한다. 2026년은 진행 중 연도로 별도 현황을 관리하며 완결 연차와 섞지 않는다. 구름·그림자·NoData를 제외한 유효 256×256 패치 1,000~3,000개가 초기 목표다. 충분성은 패치 개수뿐 아니라 주별/클래스/시기 대표성, 분할 독립성, 참조라벨 신뢰도를 함께 확인한다.

## 2. AOI와 기간

| 우선 주 | 인도네시아어 표기 | 수집 기준 |
|---|---|---|
| South Sulawesi | Sulawesi Selatan | First Group |
| Gorontalo | Gorontalo | First Group |
| Southeast Sulawesi | Sulawesi Tenggara | First Group |
| Banten | Banten | First Group |
| West Java | Jawa Barat | First Group |
| East Java | Jawa Timur | First Group |

이 명단은 사용자가 지정한 업무 우선순위다. 공개 행정경계로 주별 geometry를 확인하고 BIG/발주처의 공식 경계와 대조할 때까지 출처·버전·권위 수준을 기록한다. 주 전체 경계와 검색용 bbox,256×256 학습 표본의 실제 범위를 각각 구분한다. bbox 전체를 주 경계로 취급하지 않는다. 주 내부에서 도시/농경/산림/습지 등 대표 표본을 확보하되 주별 계절·구름 조건을 함께 검토한다.

실제 내려받은 geoBoundaries IDN ADM1 원본은34개 feature,3397843bytes다. 그중6개 대상 주를 선택했다. 원본 메타데이터의 대표연도2017, 출처OpenStreetMap/Wambacher, 라이선스ODbL1.0을 그대로 보존했다. 최신 공식 BIG 경계나 현재 인도네시아 전체 주 개수의 근거로 이 자료를 사용하지 않는다. 경계 manifest와 선택 GeoJSON은 `data/first-group-boundaries`에 있다.

기존 `configs/collection.example.json`의 3개 연구 후보와2021년 최초 baseline은 개발 시험 이력이다. 중부 자바는 위 First Group에 포함되지 않으며 그 시험을 First Group6주 실증으로 재표기하지 않는다. 최신 수집 계약은 `configs/first-group.collection.json`과 First Group 품질감사 문서를 따른다.

연차별로 가능한 같은 계절(초기 검색 예: 매년 6~9월), 같은 센서, 같은 밴드·해상도·격자, 유사한 태양/관측조건을 사용한다. 지역별 우기/건기와 구름 조건이 다르므로 현지 확인 후 계절창을 확정한다. WorldCover 2020/2021만 존재하므로 2025 라벨의 정답으로 취급하지 않는다. Dynamic World는 매년 같은 기간의 확률밴드와 신뢰도 마스크를 확보하고 관측기간 차이를 기록한다. 목표를 맞추려고 구름 임계값을 임의 완화하지 않는다.

분석쌍은 2020→2021…2024→2025의 인접연도 변화와 2020→각 연도의 기준연도 누적 변화를 모두 만든다. 연도별 가용 영상이 없으면 결측으로 남긴다. 단일 장면의 구름은 장면 전체 통계이므로 AOI별 SCL 유효면적 QA를 추가해야 한다. 연차 합성(예: 품질 마스킹 후 median)은 향후 별도 처리·검증하며 현재 단일 장면 선택을 합성영상이라고 표시하지 않는다.

## 3. 제공자와 이용조건

| 자료 | 접근 | 조건/한계 |
|---|---|---|
| Sentinel-2 L2A | Earth Search 또는 Planetary Computer STAC/COG | endpoint 연결·검색·다운로드 별도 검증, PC 자산 SAS 서명 필요 가능 |
| Landsat C2 L2 | STAC | 센서별 반사도 scale/offset 별도 적용; Sentinel 기본값 재사용 금지 |
| Dynamic World V1 | Earth Engine | 프로젝트·인증·EE 사용조건, export 제출과 완료/다운로드 구분 |
| ESA WorldCover 2020/2021 | 공식 S3 3도 타일 | CC-BY4.0, 연도·클래스 차이 기록 |
| 공식 인도네시아 토지피복/경계 | BIG/KLHK/ATR/BPN·현지기관 | 접근권한·라이선스·권위/최신성 확인 후 연계 |
| 전문가 라벨 | 등록 GeoTIFF/후속 vector 연계 | 작성자/시기/판독근거/검토이력·독립성 증빙 |

출처/권한이 미확인인 항목은 license_verified=false로 보존한다. API가 임의로 법적 허용 여부를 확정하지 않는다.

## 4. 실행 순서와 용량 관리

1. 로컬 진단으로 DNS/HTTPS/STAC 요청과 응답계약을 단계별 확인한다.
2. `collect_samples.py`의 계획 기본 모드로 AOI·기간·밴드·총용량을 검토한다.
3. 명시적 `--execute` 실행에서만 수집한다. 예제 총예산은 2GiB이며 기존 확보량과 부분파일을 포함해 점검한다. 충분한 학습자료가 이 예산 안에 들어간다고 보장하지 않는다.
4. SHA256·내용 중복·원본 보존·실패/재개 이력을 남긴다. Band 순서와 scale/offset은 센서/처리 baseline별 확인한다.
5. 원본/라벨 격자·시기·품질 확인 후 최근린 라벨정합, 구름마스크와 0.8 신뢰도 조건으로 패치 생성한다.
6. 지역 group·원본 scene_id·해시·공간겹침을 검사하고 split manifest를 고정한다.

## 5. 충분성 판정

최소6개 우선 주×6개 완결 연도의 관측 조합을 갖추고, 학습/검증/시험 모두 유효 패치가 있어야 한다. 누락 주·연도·AOI·밴드·라벨과 유효패치 수를 표로 기록한다. 한 주당 한 창만 확보하면36패치에 그치므로 충분성 기준을 통과하지 못한다. 70/15/15는 group 수와 크기에 따라 근사되며6개 주만 사용하는 초기 분할4/1/1은 약66.7/16.7/16.7이다. 클래스별 유효 픽셀·지역분포·시기분포, 저신뢰/검토대상 비율, 구름/NoData 비율을 보고한다. 드문 맹그로브/습지와 산림전환은 전문가 검토 표본을 추가한다. 같은 주의 여러 연도와 같은 장면 인접 타일은 같은 group/scene_id로 묶어 시간별 자료가 공간 hold-out을 오염시키지 않게 한다.

독립 참조라벨이 없으면 의사라벨 일치도만 보고하고 최종 정확도/운영 인수조건은 미충족으로 남긴다. 수집 스크립트가 장면을 확보했어도 라벨/유효패치/독립평가가 미확보이면 training_ready=false를 유지한다.

## 6. 실행 결과 위치

진단과 실제 수집 현황은 `docs/10_STAC_네트워크진단.md`, `data/validation-planetary/`, `data/collection/`을 확인한다. 계획·모의응답·픽셀 창 다운로드·학습용 자료 확보를 각각 다른 상태로 기록한다.
