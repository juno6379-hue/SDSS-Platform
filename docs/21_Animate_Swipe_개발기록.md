# Animate·Swipe 연차 지도 개발 기록

## 1. 개발 목적과 자료 경계

사용자의 명시 요청에 따라 플랫폼에 연차 지도 Animate와 Swipe를 추가했다. 공개 제공처를 안내하는 링크에 머무르지 않고 자체 MapLibre 화면에서 서버가 등록한 실제 GeoTIFF 타일을 표시한다. 참조지도와 모델 예측을 서로 다른 시리즈로 표시하며, 등록되지 않은 연도·분류 결과·중간 프레임을 생성하지 않는다.

초기 운영 ESRI 재고는 현재 2020년만 확보된 공간창들이므로, 확보되지 않은 2021~2025년 비교를 운영 성과로 보여주지 않는다. 한 연도는 실제 지도로 확인할 수 있지만 자동 재생·두 연도 비교를 위한 두 개 이상 연도가 필요함을 표시한다.

## 2. 병렬 개발 및 API 계약

통합 담당은 `backend/app/landcover_tiles.py`와 API를, 웹 담당은 `frontend/src/TemporalCompare.tsx`와 스타일·연결·격리 시험 자료를 구현했다. 수집 담당의 실제 수집 코드·공유 원장과 분리했으며 이 UI 검증으로 신규 외부 수집을 실행하지 않는다.

`GET /api/data/landcover-series`는 실제 가용 시리즈와 각 연도의 불투명 `layer_id`, WGS84 bbox, palette, source, reference_kind, synthetic 여부를 반환한다. 같은 주·공간 위치·창 크기·참조 소스만 연차 시리즈로 묶는다. 원본 1024창을 사용하며 추출한 패치들을 임의로 이어 붙여 시계열을 만들지 않는다. 모델 예측 시계열은 등록된 분석의 classifications에서 읽는다.

`GET /api/data/landcover-layers/{layer_id}/tiles/{z}/{x}/{y}.png`는 서버가 확인한 경로의 단일 밴드 범주형 래스터를 최근린으로 EPSG:3857 XYZ RGBA 타일로 표시한다. 원시 파일 경로를 URL로 입력하지 않는다. ESRI0·10, WC0과 모델255의 투명 처리 및 모델 water0의 파랑 처리는 구분한다. 범례는 서버가 제공한 실제 raw 코드·색·클래스 이름을 사용한다.

## 3. 구현 순서

1. 아홉 번째 메뉴 ‘연차 지도 비교’를 추가하고 실제 inventory 조회·재조회·빈 상태·오류 상태를 연결했다. 조회 실패 시 이전 자료를 현재 값으로 표시하지 않는다.
2. 가용 연도 배열을 정렬하여 Animate 재생·일시 정지, 0.5/1.5/3초 간격, 연도 slider를 연결했다. slider나 재생은 누락 연도를 건너뛰며 실제 배열만 순환한다. 연도 직접 이동은 재생을 정지한다.
3. Swipe의 왼쪽·오른쪽 연도 선택과 0~100% 비교 경계를 추가했다. 경계는 기본 HTML range이므로 마우스·터치·키보드로 조작할 수 있다.
4. 전체 크기의 두 지도를 같은 viewport로 생성하고 오른쪽 지도의 CSS clip-path만 움직인다. 두 지도를 반 너비로 재배치하지 않는다. 왼쪽 지도 이동·확대 시 오른쪽 지도 카메라를 동기화하고 오른쪽 지도는 pointer event를 받지 않아 무한 상호 move 이벤트를 방지한다. 연도를 바꿔도 현재 지도 위치·축척을 유지한다.
5. 재생 지도 위 연도 표시, Swipe 좌우 표식·경계선, 참조/모델 예측 구분, 실제 source 및 raw 코드 범례, 누락 연도, 합성 경고를 표시했다. 외부 배경지도 없이 실제 범주 타일만 표시한다.
6. API 토큰은 sessionStorage에서 읽고 정확한 자체 API 타일 prefix에 해당하는 요청에만 붙인다. URL query에 토큰을 넣거나 타사 지도 요청에 전달하지 않는다.

## 4. 검증 자료

`scripts/serve_sdss_fixture.py`는 독립 임시 데이터 루트에 2020/2021/2023년의 실제 16×16 합성 GeoTIFF를 생성한다. ESRI 원시 water1과 tree2/crops5/built7이 연도별로 달라 실제 픽셀 색상 변화가 발생한다. 0은 NoData다. 세 연도의 CRS·affine·shape는 같다. 2022·2024·2025는 생성하지 않으며 inventory가 누락으로 표시한다. 보고서·시리즈·화면에 synthetic를 표시한다. 운영 수집 자료·정확도·모델 성과와 무관한 화면 기능 시험이다.

## 5. 빌드와 브라우저 검증

첫 빌드는 TypeScript 통과·39모듈·34.91초·종료 코드 0이었다. 최종 검증 결과는 실제 브라우저 확인 후 아래에 추가한다. 지도 라이브러리를 포함한 큰 청크 경고는 기존과 같이 남아 있다.

격리 API8001·Vite5174의 실제 Chrome에서 다음을 확인했다. API 및 지도 타일은 로컬 요청이며 원격 수집을 실행하지 않았다.

| 확인 항목 | 실제 화면 결과 |
|---|---|
| 가용·누락 연도 | 확보2020/2021/2023, 누락2022/2024/2025 |
| 출처·범례 | 연차 참조·모델 예측 아님, ESRI raw코드1water/2trees/5crops/7built 등 실제 서버 palette |
| 재생 | 재생→일시정지 버튼 전환, 자동2021프레임 확인, 간격0.5초 선택 |
| 연도 slider | 키보드 End→2023(index2), 미확보2022프레임 없음 |
| Swipe | 왼쪽2020·오른쪽2023 선택, 초록trees와 빨강built가 같은 위치에 표시됨 |
| 경계 slider | ArrowRight로50→51%, Home/End로0/100%, PageUp으로50% 이동 |
| 동기 viewport | 실제 지도 드래그 후 두 연도의 파란water 바깥 경계가 일치하며 중앙만 서로 다른 분류색 |
| 합성 표시 | 전체 화면·시리즈에 합성 fixture·실제 관측/정확도 아님 표시 |

첫 프레임의 타일이 준비되기 전 로딩 문구를 표시했다. 초기 구현의 프레임별 지도 재생성은 지연을 유발해 개선했다. 최종 구현은 동일 WebGL 지도에서 raster source의 setTiles만 바꾸며 카메라를 유지한다. 개선 후에도 같은 지도 컨테이너에서 연도 이동·타일 색상 변경을 재확인했다.

최종 `npm.cmd run build`는 **TypeScript 통과·39모듈·16.73초·종료 코드0**이다. CSS80.85kB(gzip12.98kB), JS1,338.76kB(gzip373.78kB)이며 MapLibre를 포함한 큰 청크 경고만 남았다. 이 검증은 UI·타일 기능을 확인한 것이며 실제 연차 토지피복 정확도나 변화 정확도 시험이 아니다.

운영 API 재기동 후 실제 South Sulawesi/WC2021 단일연도 시리즈에서 재생 버튼·연도slider 비활성과 누락 연도 표시를 확인했다. 이후 병렬 수집으로 실제 Gorontalo/ESRIg00의2020·2021 원본 창이 확보되어 같은 운영 화면에서 재생→2021도달→일시정지를 확인했다. 실제 두 연도 Swipe50%에서도 서버 타일이 표시되었으며 2022~2025는 누락으로 남았다. 이 실자료 검증은 합성 시험과 별도이고, ESRI 약한 참조의 독립 정확도를 의미하지 않는다.
