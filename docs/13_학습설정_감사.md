# 실제 baseline 학습 설정·입력·예측 감사

감사일: 2026-10-16. 대상은 `baseline2021_cpu_v1`이며 First Group 새 모델이 아니다. 기존 실험의 연결·학습·추론 실행을 확인하고 과학적 해석의 한계를 검토한다. 재학습은 실행하지 않았다.

## 1. 실제 파일에서 확인한 근거

```powershell
python scripts/audit_training_contract.py
python -m unittest discover -s tests -p test_ml_training_contract.py -v
```

감사 결과는 `data/audits/training-contract.json`이다. 원본 영상·WorldCover 라벨·데이터셋 NPZ·manifest·실행 보고서·실제 checkpoint·분류 GeoTIFF를 직접 읽었고 각 파일 SHA256을 기록했다. 모델 checkpoint는 `weights_only=True`로 읽었으며 학습하지 않았다.

모든 원본 영상/라벨 SHA256은 데이터셋 provenance와 일치했다. 실제 WC 라벨과 원본 영상 유효 마스크에서 내부 라벨을 재구성해 세 NPZ 전체와 비교한 결과 모두 일치했다. 원본 DN에 manifest scale/offset을 적용하고 ignore 영역을 0으로 만든 결과도 실제 NPZ 입력과 모두 일치했다. 이는 **파일 간 처리 계약의 일치**이며 물리 반사도나 라벨의 지상 정확도를 입증하지 않는다.

## 2. 입력 밴드·shape·dtype

실제 순서는 **B02/B03/B04 = blue/green/red**이다. 일반적인 시각화 RGB 표시 순서 red/green/blue와 다르므로 모델 채널을 뒤집어 해석하지 않는다. 세 원본 모두 `uint16`, shape `(3,256,256)`이다. 모델 NPZ 입력은 `float32`, shape `(3,256,256)`, batch는 `(1,3,256,256)`이다. 라벨 NPZ는 `uint8`, shape `(256,256)`이고 학습 시 long으로 변환한다.

이번 모델에는 NIR, SWIR, NDVI, NDWI가 입력되지 않았다. 다른 수집 설정이 확장됐더라도 이 기존 checkpoint가 다중분광 6밴드로 학습된 것으로 바꾸지 않는다.

원본 DN의 실제 요약은 다음과 같다. 원본 영상 자체의 NoData만 제외한 통계이며 SCL 구름 제외 후의 물리 반사도 통계가 아니다. JSON에는 P0/P1/P5/P25/P50/P75/P95/P99/P100 전체가 있다.

|---|---|---:|---:|---:|---:|

|중부자바|B02|43|412|2230|14752|

manifest의 수치 변환은 `float32(DN) × 0.0001 + 0.0`이다. 평균/표준편차 정규화나 0~1 강제 clipping은 적용하지 않았다. DN이 10,000을 넘는 값도 있어 변환 후 1을 넘을 수 있다. 이것만으로 오류나 유효 반사도를 판정하지 않는다.

서자바 원본 B04의 별도 수집 보고서에서는 처리 baseline `03.00`과 N0300 제품이 확인됐다. 나머지 두 지역 처리 baseline 원문은 이번 근거에 없고, 제품의 명시적 밴드별 scale/offset도 확정하지 못했다. 따라서 **물리 반사도 변환은 미검증**이다. `s2:reflectance_conversion_factor` 같은 다른 필드를 임의로 DN scale/offset에 대입하지 않았다.

## 4. 학습 설정의 증거 수준

|항목|확인 값|근거|
|---|---|---|
|구조|Tiny U-Net, 9출력|실제 checkpoint 구조/가중치와 모델 코드|
|장치|CPU|실행 보고서|
|완료 epoch|3|실제 세 epoch 지표와 checkpoint epoch 3|
|seed|42|checkpoint 및 보고서|
|batch size|1|실험 runner의 실제 호출 설정|
|optimizer|Adam|runner가 override하지 않은 서비스 기본값|
|learning rate|0.001|같은 기본값|
|loss|CrossEntropyLoss|서비스 기본 `cross_entropy` 및 구현|
|class weights|None|runner 미지정, 서비스 기본값|
|ignore index|255|NPZ·manifest·loss 구현|

원래 checkpoint에는 optimizer state, learning rate, loss 이름, class weights가 직렬화되지 않았다. 감사 JSON은 이들 설정을 **현재 소스 기본값과 실험 runner에서 재구성한 근거**라고 명시하고 소스 SHA256을 기록한다. 이 표의 모든 값이 과거 checkpoint에서 직접 검증된 것처럼 보고하지 않는다. 이후 정식 실험에서는 전체 설정·optimizer 상태·실행 명령을 실험별로 불변 저장해야 한다.

후속 구현으로 신규 학습의 checkpoint/report에 `training_config`를 저장하도록 보완했다. 실제 optimizer/lr/loss/class weights, 요청 epochs와 별도 실행 epoch 수, batch size, patience/min_delta, precision/mixed precision, device/seed/ignore index와 입력 signature(밴드 indices 및 이름이 제공된 경우 이름, scale/offset, patch size/channels)를 직렬화한다. 설정 출처는 `serialized_actual_applied_values`이다. 선택 `band_names`를 데이터셋 manifest에 보존하되 제공하지 않은 이름을 추정해 채우지 않는다. optimizer의 전체 momentum/state 저장과 재개 학습은 이번 보완에 포함하지 않는다.

과거 `baseline2021_cpu_v1` 가중치/보고서/실지표는 덮어쓰지 않았다. 해당 기존 감사의 설정 출처는 계속 `reconstructed_source_defaults`이며 과거 미저장 한계도 유지한다. 새 저장 기능을 확인하는 추가 학습은 임시 합성 fixture에서만 수행했고 실제 세 패치 또는 신규 여섯 주 자료로 재학습하지 않았다. 비기본 SGD/lr/class weights/early stopping 설정을 실제 CPU 시험에 적용해 checkpoint/report에 남는지, 반환 객체를 수정해도 저장된 설정이 바뀌지 않는지를 검증한다.

설정 저장 보완 후 ML pipeline 12개 시험은 29.683초에 모두 통과했다. 별도 감사 보조 다섯 시험도 0.051초에 모두 통과했다. 기존 실험의 체크포인트 해시 `ad74f5cf5ab4bfd42bffd94b2fa399bf28f3527bc8e9f424d6a9d5339b12cd6c`와 보고서 해시는 등록 당시 기록에 계속 일치함을 재확인했다.

## 5. 실제 예측의 grass 단일 클래스 붕괴

세 실제 분류 GeoTIFF 각각의 65,536픽셀이 모두 **내부 코드 2, grass**였다. 각 파일 unique class는 `[2]`, grass 비율은 **100%**였다. 이를 모델이 의미 있는 다중 클래스 분류를 학습한 결과로 해석하지 않는다.

서자바 시험 WorldCover에서 grass는 846/62,672 = **1.349885%**다. 모든 유효 시험 픽셀을 grass로 예측했으므로 보고된 OA 1.349885%는 이 비율과 정확히 같다. mIoU는 약 **0.269977%**다. 이 값은 독립적인 실정확도가 아니라 WorldCover 의사라벨과의 일치도이다.

grass는 train의 다수 클래스가 아니다(train 다수는 crops 32.3293%). 따라서 단순히 “다수 클래스 불균형 때문에 grass가 나왔다”고 단정하지 않는다. 3패치/3epoch, 입력 특징 부족, 라벨/정규화 및 최적화 설정을 함께 검토해야 하며 원인을 이 단일 실험만으로 확정하지 않는다. validation loss의 작은 감소만으로 수렴이나 과학적 유효성을 주장하지 않는다.

기존 추론은 SCL 마스크가 별도 적용되지 않아 각 파일 65,536픽셀이 모두 분류됐다. 학습/시험 라벨은 WC 0 NoData로 구름·제외 영역이 제거되어 분모가 작다. 이 차이도 JSON과 기존 문서07에 남겼다.

## 6. 주장 정합과 재학습 중단 조건

기존 세 지역 실험은 **실제 위성자료를 읽어 학습·추론까지 연결되는 파이프라인 기능시험**이다. “실정확도 검증 완료”, “First Group 성능 달성”, “독립 시험 정확도”로 표시하지 않는다. 실행 보고서의 claim, 문서07·11·13은 동일한 범위를 유지한다. `scientific_accuracy_validated=false`, `independent_reference_available=false`, `first_group_performance_claim=false`를 감사에 기록했다.

다음 조건이 충족되기 전에는 새 여섯 주의 창 여섯 개만으로 학습을 반복하지 않는다.

1. 2020~2025×First Group 여섯 주의 원본/해당 시기 라벨 재고와 누락·시기 일치 검토.
2. 시기·품질 조건을 통과한 실제 256×256 패치 최소 1,000개와 주별/클래스별 대표성 검토.
3. 밴드 순서·물리 scale/offset·구름/SCL·공간 정합 검증.
4. WC/DW 의미 및 관측연도 검토와 지역/원본 장면별 고정 holdout. 독립 참조가 없으면 평가는 의사라벨 일치도로 한정한다.
5. 위 조건 이후 비교 실험을 설계하고 loss/class weighting 등을 train 자료만으로 결정.

기존 First Group 감사의 동일 주·원본 source group 전 연차 공통 분할 원칙을 유지한다. 신규 원본 공유 관계로 독립성이 깨지면 4/1/1 숫자보다 누출 방지를 우선한다.

전문가 독립 참조의 부재만으로 의사라벨 기반 개발 학습을 금지하는 것은 아니다. 충분한 데이터와 위 계약을 충족하면 WorldCover 일치도 실험으로 재학습할 수 있으나 실제 정확도 검증·운영 인수 주장은 독립 참조 확보 이후로 제한한다. 현재 중단 이유는 유효패치·검증/시험 자료·밴드 보정 검증이 부족하기 때문이다.

6밴드 연차 후속 수집은 HTTP429와 보수적 예약 예산 2GiB 소진으로 중단됐다. 완료된 추가 연차 세트는 없으며 일부 raw 창은 완료된 학습자료로 계산하지 않는다. 기존 2021 First Group의 품질 적격 세 창이라는 근거를 유지한다. 실패나 예산 중단을 추가 학습으로 덮지 않고 자료 부족과 재학습 gate를 그대로 남긴다.

## 6-1. 실험 runner와 학습 API에 연결한 gate

신규 실자료 학습은 `run_experiment.py`의 검증 계약을 요구한다. `train_model`도 실자료 manifest에서 준비 계약·파일 해시·패치 shape/개수/품질·분할별 클래스 통계를 재검증하므로 API에서 기존 세 패치 manifest를 직접 넣어 재학습하는 경로도 거부한다. 기존 `run_baseline.py`의 새 실자료 학습 경로는 폐쇄하고 정식 runner로 안내한다. 과거 결과의 `--register-report` 수동 등록 기능은 유지한다. 역사적 baseline 가중치/보고서는 변경하지 않았다.

패치 생성은 여섯 밴드와 **장면별·밴드별 scale/offset 배열**을 지원한다. 검증된 제품별 설정을 각 장면에 적용하고 provenance 및 checkpoint manifest에 보존한다. 이런 모델의 원본 DN 추론에는 그 영상 제품의 normalization을 명시해야 하며, 이를 빠뜨리면 모델의 전역 기본값을 임의 적용하지 않고 거부한다. 단일 scalar 설정으로 학습된 기존 모델은 기존 동작을 유지한다. 입력 밴드 이름이 제공됐으면 checkpoint input_signature에 저장한다.

학습 후 최적 checkpoint의 validation 및 test confusion matrix에서 실제 예측 분포를 검사한다. 적어도 두 클래스를 예측하고 한 클래스가 99.5%를 초과하지 않아야 출력 다양성 검사를 통과한다. 두 클래스 중 한 픽셀만 다르게 예측해 붕괴를 숨기는 경우도 실패한다. 실패 시 산출물은 남기되 `completed_rejected_prediction_collapse`로 기록하고 승인·배포하지 않는다. 이 다양성 기준을 통과한 것도 정확도 기준을 충족했다는 뜻은 아니다.

실자료 충분성 gate는 독립 지상정답 없이도 충분한 품질 자료에 대한 **의사라벨 일치도 실험**을 허용한다. 독립 참조의 부재는 실험 자체와 실정확도·운영 승인에 각각 다르게 적용한다. 후자는 전문가 독립 평가가 추가로 필요하다. 현재 정식 입력은 충분하지 않아 실제 추가 학습을 실행하지 않았고 합성 테스트만 수행했다.

## 7. 시험 결과

감사 보조 함수의 다섯 시험을 0.122초에 모두 통과했다. ignore/비정상 값이 비율 분모에서 빠지는지, 클래스 불균형 비율, grass 100% 단일 예측 감지, ignore뿐인 자료 처리, 정확한 WC 매핑, 실제 소스 기본설정 및 분위수 계산을 확인했다. 시험은 임시 합성 배열을 사용하며 실자료 재고에 포함하지 않는다. 실제 감사 실행은 위 실험 파일에서 매핑 일치·수치 정규화 일치·세 파일 grass 단일 예측을 확인하고 JSON으로 기록했다.

## 8. 신규 실험 설정과 재개 감사

새 대량 실험의 계약과 시험 결과는 [대량 패치 재학습 기록](17_대량패치_재학습_기록.md)을 따른다. 기존 3 epoch checkpoint를 수정하지 않고 새 checkpoint에만 실제 optimizer/lr/loss/class_weights/epochs/batch_size/patience/min_delta/precision/device/seed 및 입력 서명을 직렬화한다. train-only inverse-square-root 가중치에 validation/test 통계를 사용하지 않는다.

Esri rangeland는 과거 WC grass와 의미가 다르므로 별도 class_names와 taxonomy 서명을 저장·전달한다. 미사용 shrub 코드 5는 학습·추론 logit에서 제외하고 원본 0/10은 ignore255 처리한다. 실제 제품별 모델의 추론에는 입력 영상 SHA·scene ID·밴드 이름과 공식 제품 보정/XML 근거 해시를 재확인한다.

시간 예산 중단은 완료 실험이 아니며 test_metrics=null이다. 마지막 완료 epoch의 optimizer/RNG 상태를 원자 저장한 last.pt에서 재개하고 validation으로 선택한 best.pt를 test 평가한다. 재개 시 출처·계획·설정 변경은 거부한다. 충분성 미달 상태에서 과거 실험을 반복 학습하지 않았고 새 OA/mIoU를 생성하지 않았다.
