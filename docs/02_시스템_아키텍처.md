# 02. 시스템 아키텍처

## 1. 현재 실행 구조

React/TypeScript/MapLibre → FastAPI → 데이터·ML 어댑터 → 원본/패치/체크포인트/결과 파일. SQLite는 데이터셋·모델·작업·분석 JSON을 영속 저장한다. 무거운 작업은 단일 스레드 작업큐에서 직렬 실행한다. 서버 재시작 시 running/queued 작업은 실패로 기록해 거짓 성공을 방지한다. 현재 SQLite·프로세스 작업큐는 로컬 실증용이며 분산 작업큐가 아니다.

| 계층 | 파일 | 역할 |
|---|---|---|
| WebGIS | frontend/src/App.tsx | AOI·검색·실행·작업조회·모델승인·결과질의 |
| API | backend/app/main.py | 인증옵션/CORS/허용 도구/비동기 작업/산출물 조회 |
| 카탈로그 | backend/app/store.py | SQLite parameterized query, UTC 이력 |
| 승인 | backend/app/lifecycle.py | Draft→Validated→Approved→Deployed→Retired |
| 수집 | backend/app/data/service.py | STAC·제한다운로드·라벨계획·수동 등록·정합 |
| ML | backend/app/ml/ | 패치·누출 방지·U-Net·실제 지표·변화면적 |
| 진단 | scripts/diagnose_stac.py | DNS/HTTPS/STAC 단계분리, 로컬 재실행 |

## 2. 디렉터리와 데이터 생명주기

`data/downloads`는 수집원본을 내용 해시 이름으로 보존한다. `data/manifests`는 수집이력이다. `data/datasets/{id}`에는 패치와 split/version manifest, `data/models/{id}`에는 checkpoint/report, `data/results/{id}`에는 분류도·전이도·CSV·평가가 저장된다. 기존 ID를 덮어쓰지 않으며 새 ID로 재실행한다. API 기본 루트는 저장소 `data`이고 GEOAI_DATA_ROOT로 변경할 수 있다. 외부 경로는 허용하지 않는다.

## 3. API 계약

조회: `/api/health`, `/dashboard`, `/datasets`, `/models`, `/jobs`, `/jobs/{id}`, `/tools`, `/analyses`.

수집 현황 GET `/api/data/collection-status`는 First Group6주×6년36셀의 실제 보고서를 읽는다. 기존 확보 재고와 최근 실패를 구분하여 `cells.collection_status` 및 `latest_attempt_status`를 반환한다. 부분 창/전체 단일밴드, 별도 품질 감사 적격, 미확보, 예약 예산을 각각 표시하며 이 조회에서 외부 수집을 실행하지 않는다. `training-readiness.json`이 준비 완료를 선언해도 입력 manifest와 파일 해시가 달라지면 `stale_or_missing`으로 준비 상태를 취소한다. 보고서가 없거나 저장 중 파손돼 읽히지 않으면 unknown으로 남긴다. 상세 구현은 `backend/app/collection_status.py`다.

수집: POST `/data/search`, `/data/download`, `/data/register`, `/data/worldcover/plan`, `/data/dynamic-world/export`.

ML: POST `/datasets/prepare`, `/training`, `/inference`, `/change`. 무거운 작업은 HTTP202의 job id로 조회한다. 상태는 queued/running/succeeded/failed, 결과는 result, 실패원인은 error이다. 운영 inference는 model_id를 받고 Deployed 모델의 서버 보관 checkpoint만 사용한다. 실험 추론은 ML 모듈에서 직접 실행한다.

승인: POST `/models/{id}/evaluate`에서 전문가 독립 참조자료로 실제 추론/지표를 계산한다. 출처·검토자·그룹이 필요하며 중복 해시·공간겹침을 검사한다. 독립성은 전문가 증빙 진술과 검토에 의존한다. 평가 후에도 자동 승인하지 않으며 `/transition`에 상태/사유를 기록하고 `/deploy`로 로컬 운영 포인터를 전환한다. 외부 클라우드를 생성하지 않는다.

GET `/api/models/{id}/readiness`는 현재 체크포인트 무결성·평가 해시·대기 평가·허용 상태 전이·배포 가능 여부를 반환한다. 평가 시작 전과 완료 후 가중치 해시를 다시 확인하며 평가가 현재 가중치와 다르면 검증·승인·배포를 차단한다. POST `/api/models/register-experiment`는 `report_path`에 완료된 로컬 실험 JSON을 받고 실제 학습 보고서·데이터셋 버전·체크포인트 해시를 확인한 뒤 Draft만 등록한다. 보고서의 Approved/독립평가 플래그를 승인 근거로 수입하지 않으며 기존 ID를 덮어쓰지 않는다.

GET `/api/analyses/{id}/map-data`는 완료된 변화분석의 WGS84 GeoJSON·bbox·잘림 상태·검증 범위를 전달한다. 원본 래스터의 전체 면적 통계와 최대5000개 지도 피처는 구분한다. 변화0이면 빈 FeatureCollection과 bbox=null을 반환하며 가짜 도형을 생성하지 않는다. 서버 제공 GeoJSON은 최대8MiB로 제한한다. 지도 도형 생성/표시 성공이 변화의 독립 정확도 검증을 의미하지 않는다.

산출물: `/analyses/{id}/report`, `/artifacts/{relative_path}`. 자연어: `/query`, 사전정의 읽기 패턴으로만 근거를 조회하며 Python/SQL/셸 실행 기능을 노출하지 않는다.

GET `/api/data/landcover-series`는 실제 존재하는 연차 범주형 GeoTIFF를 동일 지역·범위·참조 출처별로 묶고 가용 연도와 누락 연도를 반환한다. GET `/api/data/landcover-layers/{layer_id}/tiles/{z}/{x}/{y}.png`는 서버가 등록한 파일을 최근린 보간한 RGBA 타일로 표시한다. 원본 경로를 요청 인자로 받지 않으며 NoData·구름은 투명 처리한다. ‘연차 지도 비교’의 Animate는 가용 연도만 재생하고 Swipe는 같은 위치·축척으로 두 연도를 비교한다. 참조자료와 모델 예측, 합성 시험자료는 별도로 표시한다. 세부 구현·실브라우저 검증은 문서21에 기록했다.

## 4. 보안과 운영 한계

개발 API는 127.0.0.1로 시작한다. 공유 환경에서는 `GEOAI_API_TOKEN`을 설정해야 한다. 단일 토큰은 RBAC가 아니며 사용자별 승인권한 분리는 후속 범위다. CORS 기본은 localhost/127.0.0.1:5173이다. 다운로드는 허용 HTTPS 호스트 및 리다이렉트 검사, 용량·재시도 제한을 적용한다. 작업 대기 개수는 20개로 제한한다. 파일 조회는 데이터 루트 안의 허용 확장자만 제공한다.

## 5. 운영 확장 결정

PostGIS: 공간 카탈로그·행정구역·RDTR geometry와 공간인덱스. Celery/RQ 또는 동등 큐: 프로세스 격리·작업재개. MLflow: 실험/모델 registry 외부 추적. OIDC/RBAC: 데이터권한과 검증자/승인자 분리. COG 타일 서버: 대형 결과 래스터 지도 표시. Object storage·Kubernetes·CI/CD·관측/드리프트·재학습 ticket·rollback: 별도 후속 체크포인트로 시험한다. 현재 구성에 연결되었다고 표시하지 않는다.
