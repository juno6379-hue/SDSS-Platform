# 2026-10-16 연차 수집 실패 분석 및 재학습 판정

## 1. 판정과 증거 범위

현재 실제 3패치·3epoch 모델은 연결·학습 파이프라인 시험이다. 세 예측 모두 grass 100%이므로 다중 클래스 구별을 학습했다고 볼 수 없다. 모델은 Draft이며 재학습·배포하지 않았다. 감사 결과는 문서12·13 및 `data/audits/alignment.json`, `training-contract.json`에 보존한다.

기존 영상/WorldCover 9쌍은 CRS·10m 격자·크기·affine·픽셀 중심/모서리·정수 라벨 검사를 통과했다. 학습 NPZ 3개의 라벨 매핑과 수치 스케일도 대조했다. 원본 WorldCover crop이 보관되지 않은 과거 쌍의 최초 재투영 자체는 재현 미검증이다. 이후 수집을 위해 원본 WC/SCL crop·해시·변환과 독립 재투영/품질마스크 재현 감사를 추가했다. 합성 시험의 재현 성공을 과거 실자료의 원본 검증 성공으로 바꾸지 않는다.

## 3. 실패 원인과 관찰값

`data/first-group-annual/run-result.json`과 chunk별 `annual-window-report.json`, `window-state.json`, 로그를 보존했다. 3작업의 종료코드는 모두2다. 36개 주-연도 셀 중35개에 검색 장면이 기록됐으나 완성 영상은0개다. HTTP429 실패27셀, 예약 예산 초과8셀, 검색 장면 없음1셀(Southeast Sulawesi 2024)이다. 검색 응답이 있다는 사실은 다운로드 성공과 다르다.

승인된 로컬 환경에서 과거 PC 서버 연결·STAC 검색·실제 영상 바이트 수신은 성공했다. sandbox의 DNS11001과 이 성공 기록을 구분한다. 이번 HTTP429는 서버 측 요청 제한 응답이며 DNS 실패가 아니다. 3개 수집 프로세스의 요청 빈도를 충분히 낮추지 못한 구현상 문제가 있다. 과거 오류 기록은 응답 호스트/Retry-After가 충분하지 않아 STAC·SAS 서명·자산 서버 중 정확한 제한 지점을 확정하지 않는다.

당시 실패 요청마다 보수적 예약을 남겨 총 예산 원장은 이전 수집 포함 **2,147,483,646bytes**가 됐다(상한2GiB=2,147,483,648bytes). 이는 실제2GiB가 수신됐다는 뜻이 아니다. 확실한 부분 crop 저장량은 위1,037,451bytes이며 원격 COG의 전송량은 압축된 로컬 파일 크기와 다르다. 과거 미측정 실패 예약을 임의로 환불하지 않는다.

요청 cloud≤20에도 과거 응답2건은20을 넘었다(South Sulawesi2022, Gorontalo2025). 해당 자료를 조건 적격으로 사용하지 않는다. 제공자 원인을 확정하지 않고 클라이언트 측 유한수/범위/상한 검사를 추가한다.

## 4. 로컬 보완과 재실행 조건

실패 후 추가 네트워크 요청을 멈췄다. HTTP429 응답에는 토큰 query를 제거한 요청 호스트·경로·Retry-After를 보존하고, 첫429에서 후속 셀과 병렬 작업을 중단하도록 보완한다. 기존 실패 실행이 이 새 보호 기능으로 실행됐다고 소급 보고하지 않는다. 측정 가능한 예외는 실제 측정한 COG 본문 바이트로 정산하고 미측정 강제중단 예약은 유지한다. 단위시험은 모의 응답을 사용하며 외부 서버 복구 검증이 아니다.

서버가 허용한 재시도 시각 이후, 네트워크·데이터 용량 예산을 확인한 새 계획에서 순차/낮은 동시성으로 재개해야 한다. 기존 소진 원장을 삭제하거나 계정·도메인·프록시를 바꿔 제한을 우회하지 않는다. 필요한 HTTPS443 대상은 `planetarycomputer.microsoft.com`과 실제 STAC 자산 href의 Azure Blob 호스트다. 현재 Sentinel 자산 허용목록은 `sentinel2l2a01.blob.core.windows.net`, `sentinel2l2a02.blob.core.windows.net`이며 WorldCover 원본은 `esa-worldcover.s3.eu-central-1.amazonaws.com`이다. 동적으로 반환된 자산 도메인을 확인하여 허용하며 모든 Azure 도메인을 무조건 허용하도록 요구하지 않는다. DNS·TLS·프록시 설정과 `Retry-After`를 각각 확인한다. 서명 URL의 SAS query는 로그에 남기지 않는다.

공식 container-token 만료 캐시는 로컬 모의 응답으로 검증했다. 이 변경 이후 실제 외부 서비스와의 재실행은 하지 않았으므로 새 경로의 실서버 호환성은 미검증이다.

## 5. 다음 데이터 구축과 재학습 조건

우선6주는 South Sulawesi, Gorontalo, Southeast Sulawesi, Banten, West Java, East Java다. 2020~2025 연차별로 동일 계절·품질 기준의 B02/B03/B04/B08(10m), B11/B12(20m)를 수집한다. 연속 반사도 밴드는 검증된 공통10m 격자로 재표본화하고 범주형 WC/SCL에는 최근린을 쓴다. B04 전체 파일과 같은 원본 확보 여부, 부분 crop 여부를 각각 기록한다.

WorldCover2020/2021은 해당 시기 약한 참조이고 2022~2025 정답으로 복제하지 않는다. 이후 연차는 실제 접근 가능한 시기 일치 공개 라벨 또는 전문가 판독 자료를 별도로 확보해야 한다. 같은 원본 장면/인접 패치와 동일 주의 전 연차는 동일 분할에 묶고, 주별 고정 train/validation/test를 사용한다. 구체적인 분할과 품질 기준은 문서11을 따른다. 현재 적격3창이 모두 train에 있어 validation/test는0이며 정식 데이터셋이 아니다.

품질 적격1,000~3,000패치 목표와 주·연도·클래스 대표성을 점검하고, train만으로 클래스 가중치/샘플링/정규화를 결정한다. 10m로 올린 SWIR가 새로운10m 관측을 만든다고 해석하지 않는다. 밴드별 제품 baseline/scale/offset을 검증한 뒤 RGB 대 다중밴드, loss 및 클래스 보정 비교를 수행한다. 새 checkpoint/report에는 실제 적용된 학습 설정을 직렬화한다.

독립 검증라벨이 없으면 WorldCover 대비 일치도만 보고한다. 실제 정확도는 별도 전문가·현장 참조 및 지역 독립 시험 설계 이후 평가한다. 여러 클래스가 구별되는지 클래스별 recall/IoU·confusion matrix·예측 비율·공간 지도를 함께 확인한다. 현재 데이터 부족을 추가 epoch 실행으로 해결했다고 주장하지 않는다.

## 6. 후속 연차 정합 감사

추가 네트워크 없이 실제 annual 세 보고서를 감사했다. `data/audits/annual-alignment.json` 결과는 pass0/fail0/**missing36**/error0이다. 완성 영상·라벨 쌍이 없어 검사할 수 없다는 뜻이며 정합 통과가 아니다. 원본 부분10파일은 학습 준비 패치에 포함하지 않는다.

## 7. 최종 로컬 통합 시험

최종 코드 동결 후 `$env:PYTHONPATH='.runtime;backend'; $env:PYTHONIOENCODING='utf-8'; python -m unittest discover -s tests -v`를 실행했다. **87개 시험이35.197초에 모두 통과(exit0)**했다. API 상태 전이/해시, 모의 DNS·HTTP429·전송량, 실제 합성 CPU 학습, 클래스 매핑·분할·정합 감사가 범위다. 외부 추가 수집 및 실자료 정확도 검증은 범위가 아니다. 라이브러리의 httpx/affine 사용 중단 예정 경고는 남아 있으며 시험 실패는 없었다.

최종 API를127.0.0.1:8000에서 재기동한 뒤 `/api/health` HTTP200을 확인했다. torch/rasterio/pyproj는 사용 가능, Earth Engine/MLflow는 미설치 상태다. 서버 건강 응답은 외부 다운로드 가능성을 보장하지 않는다.
