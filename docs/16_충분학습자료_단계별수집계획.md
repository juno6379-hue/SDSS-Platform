## 3. 실제 격자와 출처 보존

`spatial_centers()`는 주의 대표 내부점으로 UTM을 정하고 10,400m 간격 후보 중 polygon 가장자리에서 외접반경 이상 떨어진 지점을 고른다. farthest-point 순서로 주 내부에 분산하며, 각 패치에 다시 polygon 마스크를 적용한다. 지도상의 주 전체 경계와 10.24km 원본창을 혼동하지 않는다. 다른 연도의 같은 공간 위치는 같은 `spatial_location_id`를 유지하므로 시계열 반복을 새 공간 표본으로 세지 않는다.

밴드 순서는 B02/B03/B04/B08/B11/B12이다. 20m SWIR는 필요한 원본 범위+경계 여유만 읽고 B02 10m 격자에 bilinear 정합한다. SCL/참조라벨은 nearest이다. raw 밴드/SCL/WC crop, STAC 원문, 제품 XML, 각 SHA/CRS/transform/해상도를 정합본과 별도 보존한다. 정규화 scale/offset은 제품 XML과 제품 ID 일치가 확인된 경우만 `normalization` 증거로 기록한다. 영상 파일은 DN 원본값 기반이고 변환하지 않았으므로 반사도 적용완료로 표시하지 않는다.

실제 patch row는 `image_path`, `label_path`, `quality_mask_path`, `province`, `year`, `datetime`, `scene_id`, `source_group`, `spatial_location_id`, `patch_sha256`, `source_window`, `label_year/version/source_url`, `normalization`을 갖는다. source_group은 province/scene_id이며 원본scene을 다른 split에 공유하면 ML gate가 차단한다. train4주/Banten validation/West Java test를 전연도 고정한다. 적격은 전체6밴드 유효, SCL구름·그림자 제외, 라벨 존재 비율≥80%, ADM1내비율≥95%이다. 참조라벨은 동년 위성모델의 약한 라벨이며 독립 지상정답은 아니다.
