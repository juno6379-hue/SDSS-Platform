## 1. 과거 원장 보존과 신규 상한

사용자의 나머지 작업 진행 및 1000~3000패치 자료 확보 요청에 따라 신규 전역 예산을 **4,294,967,296바이트(4GiB)**로 제한한다. 이전 실험의 2GiB 한도를 지웠거나 초기화한 것이 아니라 새 실험의 추가 상한이다.

|---|---:|

기존 `first-group-annual/run-result.json`과 `first-group-recovery32/run-result.json`의 SHA256을 신규 전역 원장에 고정한다. recovery 원장은 이미 앞선 원장을 포함하므로 두 숫자를 중복 합산하지 않는다. 실제 디스크 여유는 실행 계획 JSON에 기록하며 최소 8GiB를 요구한다. 이번 계획 작성 시 여유는 약 1.999TB였다. `service.HARD_MAX_BYTES=2GiB` 개별 자산 상한은 바꾸지 않았다. 원격창 batch는 64MiB COG+1MiB 메타데이터, 전체 신규 예산은 공통 `data/first-group-training-budget/global-ledger.json`으로 관리한다.

요청 전에 batch 상한을 예약하고 정상 포착된 종료에서 실제로 측정되거나 보수적으로 남은 COG 예약+메타 본문으로 정산한다. 강제종료 후 미측정 pending 예약은 자동 환불하거나 다른 경로로 재실행하지 않는다. 잠금 파일은 모든 stage가 공유하며 수집 프로세스는 한 개만 허용한다. 기존 HTTP429 예약도 환불하지 않는다.

## 2. 실행 순서

1. 나머지 훈련 4주 South Sulawesi, Gorontalo, Southeast Sulawesi, East Java의 **2021년 256×256 6밴드**를 먼저 수집한다. 기존 Banten/West Java 보충 결과는 그대로 보존한다.
2. 6주×2020/2021에 대해 공개 ADM1 polygon 내부에 떨어진 최대16개 원본창을 선정한다. 원본창은 1024×1024, 10m 기준이며 한 번 읽어 로컬에서 비중복256패치16개로 나눈다. 최대 192개 원본창, **명목3072개 후보**이다. 이 숫자는 유효 패치 확보량이 아니다.
3. 충분성 목표는 실제 유효 후보1200개, train≥600/validation≥100/test≥100, 6주×2개 선정연도 coverage를 충족하면 일단 수집을 멈추고 독립 감사로 넘긴다. 예산·429가 먼저 발생하면 즉시 중단한다. 최종 학습허가는 ML의 클래스·누출·출처 검증까지 통과해야 한다.
4. 2022~2025는 공식 Esri Explorer의 공개v003 연차 참조로 확장할 수 있도록 adapter를 구현했다. **WC2021을 후속연도 정답으로 복제하지 않는다.** 원본선택scene의MGRS supercell과실제연도별파일명을사용하며2024이상/2023이하파일기간규칙을구분한다. 실제사용하려면별도ESRI output을지정한다. 6주×6년×4공간창은2304명목후보로,실확보/전체2020~2025 달성은여전히false이다. raw원본에서공식값0/1/2/4/5/7/8/9/10/11이외값이면라벨을거부하고0/10은ignore처리한다. Rangeland를포함한별도taxonomy로WC와무표시혼합하지않는다.

## 3. 실제 격자와 출처 보존

`spatial_centers()`는 주의 대표 내부점으로 UTM을 정하고 10,400m 간격 후보 중 polygon 가장자리에서 외접반경 이상 떨어진 지점을 고른다. farthest-point 순서로 주 내부에 분산하며, 각 패치에 다시 polygon 마스크를 적용한다. 지도상의 주 전체 경계와 10.24km 원본창을 혼동하지 않는다. 다른 연도의 같은 공간 위치는 같은 `spatial_location_id`를 유지하므로 시계열 반복을 새 공간 표본으로 세지 않는다.

밴드 순서는 B02/B03/B04/B08/B11/B12이다. 20m SWIR는 필요한 원본 범위+경계 여유만 읽고 B02 10m 격자에 bilinear 정합한다. SCL/참조라벨은 nearest이다. raw 밴드/SCL/WC crop, STAC 원문, 제품 XML, 각 SHA/CRS/transform/해상도를 정합본과 별도 보존한다. 정규화 scale/offset은 제품 XML과 제품 ID 일치가 확인된 경우만 `normalization` 증거로 기록한다. 영상 파일은 DN 원본값 기반이고 변환하지 않았으므로 반사도 적용완료로 표시하지 않는다.

실제 patch row는 `image_path`, `label_path`, `quality_mask_path`, `province`, `year`, `datetime`, `scene_id`, `source_group`, `spatial_location_id`, `patch_sha256`, `source_window`, `label_year/version/source_url`, `normalization`을 갖는다. source_group은 province/scene_id이며 원본scene을 다른 split에 공유하면 ML gate가 차단한다. train4주/Banten validation/West Java test를 전연도 고정한다. 적격은 전체6밴드 유효, SCL구름·그림자 제외, 라벨 존재 비율≥80%, ADM1내비율≥95%이다. 참조라벨은 동년 위성모델의 약한 라벨이며 독립 지상정답은 아니다.

## 5. 사용자 병렬수집 추가지시와 v2 인계

사용자의 실제 수집 병렬화 요청에 따라 독립 coordinator의2worker를 설계했다. 과거3process의429 이력을 감안해 agent마다 각자 수집 프로세스를 띄우지 않는다. 하나의 coordinator/공유4GiB원장/전체공통2초요청간격/첫429공유Event중단을 사용한다. 예약·정산·합산manifest는부모스레드에서만수행하고,worker는서로다른batch경로의COG원장과thread-local메타계측을사용한다. 이미시작된응답의측정/정산은끝내되429관찰뒤새HTTP요청과새batch를시작하지않는다.

초기6batch(v1) 실행이끝나기전에는기존서비스/collector를동결했다. `app/data/parallel.py` 실행기와`collect_training_parallel.py`독립coordinator를먼저작성하고두worker실제중첩/중앙정산/첫중단뒤후속작업미제출을네트워크없이시험했다. 서비스계측/회로후크와source품질기준분리는초기실행종료후연결한다. 이개발순서를실제병렬수집성공으로표시하지않는다.

초기실행종료후메타계측을thread-local로변경하고`configure_request_circuit()`/`request_circuit_status()`를연결했다. `_open()`은전역간격대기전후공유Event를재검사하며,실제HTTP429의host/path/Retry-After를처음관찰한worker가즉시공유한다. 다른worker의미전송요청은`SharedCollectionStop`으로구분하여새서버429응답으로집계하지않는다. 52개데이터시험을통과했고메타예산10B/20B인두worker의8B응답계측이각각분리됨과첫429뒤실제추가HTTP호출0회를모의확인했다.

root는동일전역원장으로`python scripts/collect_training_parallel.py --max-batches 2 --output data/first-group-training-esri-v1 --execute`를실행했다. South Sulawesi2020/Gorontalo2021의서로다른thread가동시에시작한로그를확인했다. 이는실제2worker시작증거이며두batch완료·전체목표달성과는다르다. 진행중서비스/collector/coordinator는동결하고다른agent가독립수집을중복실행하지않는다.

후속실제종료: 두batch는429없이완료했고각20,408,281B/19,583,652B를정산했다. 생성된물리패치는32개지만최종적격은13개추가로누적90적격/112물리다. source65%하한을최종80%적격으로오인하지않는다. 전역신규계상153,106,741B/이전포함2,314,943,200B이며새예산을추가하지않았다.

### 추가공간후보를 포함한 같은예산 재개
