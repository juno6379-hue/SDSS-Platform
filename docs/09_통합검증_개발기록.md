# 09. 통합 개발과 검증 기록

최신 체크포인트: 2026-10-16. 실제 2021년 3지역 RGB/WorldCover, B04 원본 단일밴드 전체 파일, CPU 학습·추론과 로컬 화면 연계까지 확인했다. 2020~2025 전 연차 자료와 충분한 학습표본은 아직 확보하지 못했다.

후속 사용자 지시로 First Group6주(South Sulawesi/Gorontalo/Southeast Sulawesi/Banten/West Java/East Java)를 수집 우선순위로 변경했다. 기존 중부 자바 포함3지역 실험은 역사적 시험으로 유지한다. 이후6주 수집 결과는 문서10/11에서 구분한다.

## 1. 개발 순서

2026-10-15 빈 폴더를 조사한 뒤 사용자 마스터 명령서를 읽고 세 에이전트를 병렬 배정했다. 총괄은 API/SQLite 카탈로그/작업큐/모델승인을, 데이터 담당은 STAC·다운로드·라벨어댑터를, 모델 담당은 패치·U-Net·추론·변화를, 화면 담당은 React·MapLibre·API 연계를 맡았다.

사용자가 지정한 G: 기술제안서 폴더는 정상 파일접근 승인 후 TECH-4/5 및 준수표를 읽었다. 원문 요구와 상세 구현 선택을 docs01에 구분하고 TECH-5의 27개월 D1~D21을 이번 체크포인트와 혼동하지 않도록 docs03에 연결했다. 한국어 개발 주석과 모듈별 실행·한계 기록을 남겼다.

입력/출력 계약을 먼저 합의한 뒤 작업큐에 동기 어댑터를 연결했다. API의 학습/수집/변화는 202 job으로 반환한다. 실패는 failed+error로 영속 저장하며 실제 결과가 없을 때 빈 catalog를 반환한다. 운영 추론은 Deployed 모델만 받는다.

```powershell

$env:PYTHONIOENCODING='utf-8'
python -m unittest discover -s tests -v

docker compose config --quiet
```

2026-10-16 체크포인트 해시 변조 차단·품질마스크·수동 결과 등록까지 반영한 통합시험은 **49개,28.018초,OK**다. First Group후속 변경은 별도 최종 실행 결과를 추가한다.

## 4. 실제 위성자료 증거

`data/validation-planetary/diagnosis.json`에서 서버 연결·STAC 검색·64×64 B04 픽셀 창 다운로드가 모두 성공했다. 영상 ID `S2A_MSIL2A_20230921T025531_R032_T48MXT_20240913T192557`, 촬영 UTC2023-09-21T02:55:31.024, 구름3.829685%. 부분 GeoTIFF6479bytes, 실제 HTTP본문458966bytes, SHA256 `20ff68559b352349744beff0de17e11ad54a0174ae4a73a48c7d9bbe7d3e2a0f`.

이는 원본 전체장면, 다중밴드 학습자료 또는 독립라벨을 확보한 것이 아니다. 사용자 연차별 지시에 따라 2020~2025×3지역 수집계획으로 확대했다. 연도별 실제 확보량·누락은 수집 보고서를 기준으로 갱신한다. 초기 합성 CPU 시험의 정확도를 실제 Sentinel-2 정확도로 보고하지 않는다.

## 5. 실자료 최초 학습과 원본 파일 검증 (2026-10-16)

서부 자바·중부 자바·남술라웨시 후보 AOI의 2021년 실제 RGB256×256 3개와 SCL 품질 마스킹/정합된 WorldCover 라벨3개를 확보했다. RGB 파일은 295932/301704/308075bytes, 라벨은 6908/6286/7639bytes이며 HTTP본문 누적8912896bytes를 기록했다. 유효 참조 비율은 95.6299%/99.6399%/98.2239%다. 이 창들은 원본 전체장면과 구분한다.

추가로 서부 자바 2021년 B04 **원본 파일 전체221758050bytes**를 수집했다. GTiff10980×10980, EPSG32748,10m, 실제32×32 창 읽기에서 DN832~6888을 확인했다. SHA256 `ee3979574239b669bdccc4b571623ddb02be484c0b9c29179fd627a4071a1453`, 출처와 처리baseline03.00은 `data/raw-reference/reference-report.json`에 보존한다. 전체 단일밴드 파일이며 모든 밴드를 확보한 것은 아니다. 명시적인 raster:bands scale/offset은 원문에서 없으므로 물리 반사도 검증 완료로 표시하지 않는다.

`scripts/run_baseline.py`로 실제3지역을 train/val/test 각1패치로 나누어 CPU3epoch를 실행했다. **OA1.35%, mIoU0.27%**는 WorldCover 약한 참조라벨 일치도다. 출력이 초지 한 클래스로 쏠리는 성능 저하를 그대로 보존하며 운영 적합 모델로 보고하지 않는다. 3패치는 1,000~3,000 목표에 훨씬 못 미치고 70/15/15 비율을 만족하지 않는다. DN×.0001/offset0은 명시 실험설정이며 제품 메타데이터 대조가 추가로 필요하다. 기존3분류의 추론은 SCL 마스크가 빠진 한계가 있고, 이후 모듈은 quality_mask_path를 명시적으로 받도록 보완했다. 기존 결과를 새 결과로 덮어쓰지 않았다.

모델 `baseline2021_cpu_v1_model`은 checkpoint 해시를 검증하여 **Draft, independent_evaluation=false**로 등록했고 데이터셋1개와 분류결과3개를 카탈로그에 연결했다. 등록 영수증과 source/checkpoint lineage를 보존했다. 배포와 운영 실행 직전에 체크포인트 해시를 재검증하며 대기 중 폐기된 모델과 중복평가/평가 중 승인 전이를 차단한다.

## 7. 후속 인수조건

현재 우선 범위인 First Group6주×2020~2025의36 AOI-연도 조합에서 충분한 다중밴드·품질마스크·시기별 라벨, 1,000~3,000 유효패치와 독립 참조평가가 필요하다. U-Net++, 지역/시기별 오차지도, 자동 라벨불일치 검토, MLflow/PostGIS·RBAC·실제 RDTR·GeoRAG·운영 관측/복구·현장 UAT는 미완료 항목이다. 실증 미완료를 전체사업 완료로 표시하지 않는다.

초기의18개 조합 추가 검색은 당시 승인 도구가 rejected by user를 반환하여 수행하지 않은 이력이다. 이후 승인된 First Group36셀 실행과 구분한다. 충분한 자료 확보를 위한8×8 공간표본 계획은 명목1152패치 후보이며 그 표본망 실행은0, 품질 제외 후 유효1000개를 보장하지 않는다.

## 8. First Group 실제 품질 감사 및 연차 수집 실패

후속 First Group2021 RGB/WorldCover는6주 모두 확보했다. ≥80% 유효품질 기준을 만족하는 창은3개이며 고정 지역 분할의 train3/validation0/test0이므로 정상 학습 데이터셋은 아직 아니다. 실제 경계는 geoBoundaries IDN ADM1의2017 대표/ODbL1.0 자료이며 최신 BIG 공식 경계 확인과 구분한다. 프런트엔드 최종 검증은35modules,16.12초,exit0이며6주 선택과 실제 경계/작은 검색bbox 표시를 브라우저에서 확인했다. 소스 등록 후 카탈로그는 데이터셋4/모델1/분석3이다.

문서12·13의 실제 감사에서 기존 영상/라벨9쌍 격자 정합과 학습 NPZ3개 매핑/수치 스케일 일치를 확인했다. 과거 원본 WC crop 재투영 재현은 미검증이다. 학습용 유효64,372픽셀에 관목/설빙0, 나지133(0.2066%)이었고 예측3개는 grass100%였다. 최초3patch/3epoch는 기능시험으로만 유지한다. 신규 checkpoint/report에는 실제 학습 설정을 직렬화하도록 보완했고 과거 실험 파일과 등록 해시는 변경하지 않았다.

후속36셀6밴드 실제 실행은 HTTP429=27셀, 예산초과8셀, 장면없음1셀로 종료됐다. 완성6밴드+라벨0쌍, raw부분10파일1,037,451bytes다. 예약/이전사용 포함2,147,483,646bytes 원장은 실제2GiB수신을 의미하지 않는다. 추가 네트워크를 멈추고429회로차단·측정실패정산·cloud응답상한검사를 보완한다. 연차 정합 감사는36쌍모두missing이다. 상세 원인과 밴드 확보 계획은 문서14를 따른다.

후속 보완까지 포함한 최종 통합 unittest는 **87개/35.197초/exit0**이다. 모의 응답과 임시 합성 CPU 시험을 포함하며 외부 서비스 복구 또는 과학적 정확도 검증 성공을 의미하지 않는다. 최종 API 재기동 후 health HTTP200을 확인했다. 기존49개 시험 기록은 앞선 코드 시점의 이력으로 남긴다.
