# 영상·WorldCover 라벨 정합 독립 감사

## 1. 결과와 해석

2026-10-16 현재 보관 파일을 직접 읽은 결과, `baseline2021`의 3개 영상·라벨 쌍과 `first-group-2021`의 6개 쌍, **총 9개 쌍의 격자 정합 검사는 통과**했다. 모든 쌍은 영상 3밴드·라벨 1밴드, 256×256픽셀, 10m×10m 격자다. 같은 쌍의 CRS·shape·resolution·정확한 affine 계수·4개 격자 모서리·첫 픽셀 중심이 일치한다. 정렬본 라벨의 값은 0 또는 허용된 WorldCover 원형 코드이며 라벨 NoData는 0이다.

현재 학습 데이터셋의 **NPZ 3개는 독립적으로 다시 계산한 라벨과 픽셀 단위로 모두 일치**한다. 클래스 수, 반사도 스케일 적용 영상, 제외 영역의 영상 0, 원본 파일 SHA-256도 일치했다. 학습 함수가 반환한 통계를 그대로 믿지 않고 별도의 매핑표와 배열 비교로 확인했다.

이 결과로 원본 WorldCover의 지상 정확도나 클래스 정의의 동등성이 입증되지는 않는다. 기존 9쌍의 원본 WorldCover 다운로드 crop은 당시 수집 함수의 메모리 안에서 재투영된 후 소멸했다. 이 9쌍에 보관된 것은 정렬·품질 마스킹 후 GeoTIFF와 등록 manifest다. **기존 원본 crop을 다시 다운로드하지 않았으며 이 9쌍의 원본 crop→정렬본 재투영 픽셀 재현은 미검증**이다. 신규 annual 수집의 원본 보관·재현 기능은 아래 8절에 구분해 기록한다.

감사 JSON은 `data/audits/alignment.json`에 저장했다. 이 감사는 네트워크 요청 0회, 재학습 0회, 기존 자료 변경 0회로 수행했다. 출력 JSON과 임시 시험 파일만 생성했다.

## 2. 수행 순서와 근거 파일

1. 두 `annual-window-report.json`에서 실제 영상·라벨 경로를 읽었다. 최신 실행 시점에는 Gorontalo 재수집이 완료되어 6개 주 모두 쌍이 존재했다. 보고서의 성공 수치를 그대로 복사하지 않고 각 래스터를 열어 검사했다.
2. `window-state.json`에 등록된 최종 라벨 hash와 실제 파일 hash를 대조했다. 총 9개가 일치했다. 원본 WorldCover URL도 이 보관 기록에서 확인했다. 현재 2021 라벨은 ESA WorldCover v200 2021이다.
3. Rasterio로 CRS, 높이·너비, 밴드 수, dtype, 해상도, 6개 affine 계수, 모서리 좌표, 첫 픽셀 중심, NoData와 read mask를 읽었다.
4. 정렬 라벨의 unique 값과 빈도를 직접 계산하고 독립 매핑표로 0~8 및 ignore 255를 계산했다.
5. `backend/app/ml/dataset.py`를 실행하지 않고 AST로 실제 매핑 상수만 읽어 독립 매핑표와 비교했다.
6. `scripts/collect_samples.py`의 실제 `reproject(labels[0], ...)` 호출을 AST로 검사해 `Resampling.nearest`임을 확인했다. 연속형 영상 밴드의 bilinear 처리와 구분했다. 이는 현재 소스 증거이며 과거 실행 파일 hash까지 보관된 재현 증거는 아니다.
7. `data/datasets/baseline2021_cpu_v1_dataset/manifest.json`의 provenance와 패치 좌표에서 기대 NPZ를 독립 복원하고 실제 `.npz`의 모든 픽셀과 비교했다.

## 5. 0과 255, 품질 마스크의 구분

원형 WorldCover 파일의 0은 라벨 NoData다. 수집기는 Sentinel-2 SCL의 0/1/3/8/9/10/11과 영상 DN 0을 제외한 뒤 해당 위치의 정렬 라벨을 0으로 만든다. 따라서 정렬본의 라벨 0은 원래 WorldCover NoData, 영상 NoData, SCL의 구름·그림자·기타 제외가 합쳐졌을 수 있다. **별도 SCL/품질 마스크가 없으면 원인별 개수를 역산할 수 없다.**

학습 준비 단계에서는 원형 WorldCover 80을 학습 클래스 0(water)으로 바꾼다. 원형 0과 유효하지 않은 위치는 255(ignore)로 바꾼다. 즉 원형 라벨 0, 별도 품질 마스크 0, 학습 클래스 0은 서로 다른 의미다. 학습 라벨에 `nodata=0`을 재적용하면 실제 water를 지울 위험이 있으므로 npz의 255를 제외값으로 사용해야 한다.

실제 보관 NPZ에서는 다음이 확인되었다.

| 패치 | 그룹/분할 | 학습 클래스별 픽셀 수 | ignore 255 | label 불일치 |
|---|---|---|---:|---:|
| 0_0_0.npz | west_java_candidate / test | 1:40,598 · 2:846 · 4:8,367 · 6:12,853 · 7:8 | 2,864 | 0 |
| 1_0_0.npz | central_java_candidate / val | 1:44,602 · 2:3,167 · 4:1,116 · 6:16,355 · 7:60 | 236 | 0 |
| 2_0_0.npz | south_sulawesi_candidate / train | 0:850 · 1:18,006 · 2:8,199 · 3:446 · 4:20,811 · 6:15,927 · 7:133 | 1,164 | 0 |

남술라웨시 원형 water 80의 850픽셀이 학습 클래스 0의 850픽셀과 일치했다. 이와 별개로 원형 라벨 0의 1,164픽셀은 학습 ignore 255의 1,164픽셀로 보존되었다. 세 패치의 원본 라벨 class count와 학습 라벨 count 사이에 구현상 mismatch는 발견되지 않았다.

## 7. 남은 QA와 다음 단계

원본 WorldCover crop과 source affine, 다운로드 바이트 hash, 적용한 SCL crop과 코드 버전 hash를 함께 보관해야 원본→최종 라벨의 최근린 재투영을 독립적으로 완전 재현할 수 있다. 기존 보관본에 없는 원본을 재다운로드했다고 가정하지 않는다. 이번 감사에서는 새 다운로드를 실행하지 않았다.

이 감사의 범위는 정합·코드 매핑·NPZ 변환이다. 모델 학습률·손실함수·클래스 불균형·예측 분포·보정 파라미터 평가는 별도 모델 담당 감사 범위다. 새로운 재학습은 이 QA 결과와 미해결 라벨 의미 검토를 먼저 검토한 뒤 진행해야 한다. 본 감사 과정에서 재학습이나 기존 모델 교체를 하지 않았다.

## 8. 신규 연차별 원본 crop 독립 재현 기능

후속 `data/first-group-annual/chunk-01~03` 수집에는 `source_crops` 보관 계약이 추가되었다. 신규 감사 함수는 이 계약의 `raw-worldcover.tif` 및 `raw-SCL.tif`에 대해 `path`, `sha256`, `transform`, `resampling_applied:false`를 읽는다. 원격 URL을 다시 열지 않는다. 기존 9쌍의 기록에 없는 원본 파일을 있는 것으로 가정하지 않는다.

독립 재현은 다음 순서로 수행한다.

1. 보관 WorldCover 원본 crop의 실제 CRS·affine·shape·코드 분포를 읽고 archive SHA-256과 원래 affine를 대조한다. 보간 전 보관 상태도 확인한다.
2. 원본 crop에서 새 배열을 만들고 영상의 정확한 대상 CRS·affine·shape로 **최근린** 재투영한다. source/destination NoData는 0이다.
3. 저장된 `quality-mask.tif`의 격자가 영상과 일치하고 값이 0/1인지 확인한 뒤 0 위치를 라벨에서도 0으로 만든다.
4. 최종 저장 라벨과 전체 픽셀을 비교한다. 합법 WorldCover 코드로만 바뀐 오류도 탐지한다. 클래스 수가 같은 위치 바뀜 역시 픽셀 비교에서 탐지한다.
5. 보관 SCL이 있으면 이를 독립적으로 최근린 재투영하고 SCL 0/1/3/8/9/10/11 제외 및 전 영상 밴드 DN 0 제외로 기대 품질 마스크를 새로 만든다. 저장 품질 마스크와 모든 픽셀을 비교한다. 저장 mask와 최종 label을 함께 잘못 수정한 경우도 원본 SCL 비교로 탐지한다.

`source_reconstruction.status`는 pass/fail/unverified를 구분한다. 원본 crop·저장 품질 마스크가 없는 기존 행은 **unverified**다. 원본 WorldCover의 재현에 성공해도 보관 SCL이 없으면 품질 마스크 의미 검증은 별도 unverified로 남는다. SHA나 재현 픽셀이 다르면 fail이고 행 전체도 fail로 승격한다. 이 값들은 격자 PASS나 실제 모델 정확도와 구분한다.

신규 영상은 6밴드일 수 있으므로 기대 밴드 수는 보고서의 실제 `bands` 길이에서 읽어 검증한다. 2020/2021의 실제 WorldCover 라벨만 재현 대상으로 삼는다. 2022년 이후 영상만 있고 동일 연차 라벨이 없는 행은 **missing** 및 향후 참조 계획으로 남기며 검증 완료 건수에 넣지 않는다.

신규 시험은 coarse 20m 원본을 10m 영상으로 최근린 정합하는 성공 사례와 최종 라벨 1픽셀 변조, 품질 mask·최종 label 동시 변조, archive hash 불일치, 기존 원본 crop 미보관, 2023년 참조 라벨 미확보를 포함한다. **총 13개 시험 PASS, 2.931초**로 확인했다. 이 사례들은 임시 시험 래스터이며 실제 수집 성과로 합산하지 않는다.

실제 annual 자료에 대한 감사는 **수집이 끝난 뒤 통합 담당자가 한 번 실행**한다. 이 기능 추가 과정에서는 진행 중인 annual 보고서를 성공 결과로 감사·집계하지 않았다. 예시 실행은 다음과 같다.

```powershell
$annualReports = @(
  'data/first-group-annual/chunk-01/annual-window-report.json',
  'data/first-group-annual/chunk-02/annual-window-report.json',
  'data/first-group-annual/chunk-03/annual-window-report.json'
)
python scripts/audit_raster_alignment.py --reports $annualReports --manifests --output data/audits/annual-alignment.json
```

`--manifests`에 값을 주지 않은 위 명령은 신규 annual 래스터만 검사한다. 기존 학습 NPZ 검사까지 포함하려면 해당 manifest 경로를 전달한다. 신규 결과에는 `source_reconstruction_summary`가 추가되며 각 행에 원본 메타데이터·최종 픽셀 불일치 수·SCL 품질 마스크 불일치 수가 남는다.

## 9. 후속 수집 상태와 재감사 조건

현재 보관된 `data/audits/annual-alignment.json`은 신규 annual 36개 셀 모두 **missing**, 재투영 검증 완료 **0건**이다. 원본 재현 코드의 시험 통과를 실제 36개 셀 확보 또는 정합 통과로 해석하지 않는다. 해당 수집에는 HTTP 429 제한과 예산 제한 등이 기록되어 있고 기존 2021년 6개 주의 성공 재고와 다른 실행 기록이다.

수집 담당자와 확인했을 때 이후 새로 완성된 영상·라벨 pair는 0건이었다. 따라서 이번 웹 상태 표시 작업에서는 새 감사 결과를 만들거나 기존 감사 JSON을 덮어쓰지 않았다. 보충 수집에서 실제 image/label/quality/raw WorldCover/raw SCL·manifest가 완성되면 해당 신규 보고서만 지정해 독립 감사를 실행한다. 원본이 없는 기존 9쌍의 격자 검사 PASS와 원본 재현 unverified 상태는 그대로 구분한다. 2022년 이후 같은 연차 라벨 미확보는 여전히 missing이며 과거 WorldCover를 해당 연도의 정답으로 자동 대체하지 않는다.

## 10. 복구 수집의 신규 6밴드 실자료 2쌍 감사

이후 통합 담당자가 한정된 보충 수집을 완료하여 `data/first-group-recovery32/annual-window-report.json`에 Banten/2021과 West Java/2021의 실제 완성 pair 2개가 추가되었다. 이 보고서만 대상으로 다음 읽기 전용 감사를 실행했다. 기존 9쌍 및 실패한 annual 36셀 감사 JSON은 덮어쓰지 않았다.

```powershell
python scripts/audit_raster_alignment.py --reports data/first-group-recovery32/annual-window-report.json --manifests --output data/audits/recovery32-alignment.json
```

**실제 실행 종료 코드 0, 격자 PASS 2건, 원본 재현 PASS 2건, fail/missing/error 각 0건**이다. 학습 NPZ는 이 명령에서 검사하지 않았고 새 학습도 실행하지 않았다.

| AOI / 연도 | 실제 영상 | 원본 WorldCover | 최종 라벨 불일치 | SCL→품질 마스크 불일치 | 라벨 제외 0 |
|---|---|---|---:|---:|---:|
| Banten / 2021 | 6밴드·EPSG:32748·256×256·10m | EPSG:4326·512×512 | 0 | 0 | 260 |
| West Java / 2021 | 6밴드·EPSG:32748·256×256·10m | EPSG:4326·512×512 | 0 | 0 | 24 |

실제 영상 밴드는 B02/B03/B04/B08/B11/B12다. 보관된 보간 전 WorldCover crop의 원래 CRS·affine를 읽어 영상 격자에 최근린으로 새로 재투영하고 저장 품질 마스크를 적용했을 때 최종 라벨과 모든 픽셀이 일치했다. 별도의 원본 SCL crop을 최근린 재투영하고 전 영상 밴드 DN 0 및 지정 SCL 제외 코드를 적용해 재계산한 품질 마스크도 모두 일치했다. 보관 원본 crop·최종 등록 라벨의 해시도 일치했다. 추가 원격 다운로드 없이 검사했다.

유효 비율은 Banten 99.603271484375%, West Java 99.96337890625%이며 100%로 간주하지 않는다. 웹 표는 소수 둘째 자리까지 표시해 각각 99.60%, 99.96%로 보인다. 새 자료가 기존 2021년 재고를 갱신하므로 고유 주·연도 재고 수가 6에서 8로 늘어났다고 해석하지 않는다.

제품 XML에 근거한 calibration 검증과 반사도 변환 적용 여부는 다르다. 담당자가 제품 XML의 scale 0.0001·offset 0 확인을 보고했으며 수집 영상은 원본 DN을 유지한다. `reflectance_conversion_verified:false`를 제품 calibration 증거 없음으로 단정하지 않는다. 본 감사는 격자·범주 라벨·품질 마스크 재현을 검증했고, 실제 학습 입력의 확인된 normalization 적용 여부는 별도 학습 계약 검사에서 판정한다.

현재 신규 자료는 2021년 2개 창뿐이다. 전체 36셀·최소 1,000패치·지역별 train/val/test·독립 검증을 충족했다는 주장은 하지 않는다. 원본 재현 PASS와 모델 과학적 정확도는 별도이며 WorldCover 의미 통합의 전문가 검토 역시 남아 있다.
# 후속: 공간 패치와 ESRI 연차 라벨 감사

1024² 원본 창에서 추출한 256² 패치는 source_window/window_in_source를 결과 행에 보존하고 원본 crop의 CRS·affine에서 최종 패치 affine로 직접 최근린 재투영한다. 원본과 패치가 같은 공간 범위라는 가정을 하지 않는다. 원본 SHA는 파일 통계가 같은 경우 프로세스 내 캐시하며 변경되면 재계산한다. 원격 파일을 재수집하지 않는다.

WorldCover 기존 매핑과 ESRI 매핑은 분리했다. ESRI 독립표는 1→water0, 2→tree1, 4→flooded3, 5→crops4, 7→built6, 8→bare7, 9→snow8, 11→rangeland2이며 원본0·cloud10은 학습 ignore255다. 백엔드 매핑 상수를 AST로 읽어 독립표와 대조한다. rangeland는 grass+shrub 의미이고 WC grass와 동일 의미라는 주장은 하지 않는다. 원본 ESRI crop 최근린→SCL 품질 제외→ESRI cloud10 제외를 재현한다. 공간 패치 품질은 추가로 공개 주경계 내부·유효 라벨·유한값/비영6밴드를 적용한다. 현재 수집기의 경계 파일은 고정 로컬 공개 GeoJSON을 읽어 현재 SHA를 기록하지만 수집 당시 경계 SHA가 별도 저장되지 않았다는 한계를 표시한다.

감사 범위는 명시한 보고서 전체 행과 가용 지원 라벨 쌍의 모든 픽셀이다. 표본 추출은 하지 않으며 전체 주 면적·전체 제공처 COG를 전수 검증했다고 표현하지 않는다. 완료 전 신규 수집 보고서는 성공 증거로 포함하지 않는다. 원본 없는 기존 쌍은 여전히 원본 재현 unverified이며, 미확보 연차는 missing이다. 격자·원본 픽셀 재현 통과와 독립 지상 정확도는 별도다.

후속 감사 시험은 `python -W ignore -m unittest discover -s tests -p test_raster_alignment_audit.py`로 **18개 통과(2.923초)**했다. 큰 원본 창의 이동된 패치·ESRI cloud10/water1·주경계 강화 품질·해시 캐시 변경 감지 등을 포함한다. `data/first-group-training-v1/annual-window-report.json` 신규 WC2쌍은 전 픽셀 감사하여 `data/audits/training-v1-alignment.json`에 저장했고 raster2/source2 모두 pass다. ESRI 수집 실행은 이 기록 시점 진행 중으로 실제 신규 결과 성공을 아직 주장하지 않는다.

## ESRI 실제112패치 스냅샷 전수 감사

병렬 수집이 진행 중이므로2026-10-16 현재완료된 행만 한 번 읽어 `data/audits/esri-v1-snapshot-20261016/annual-window-report.json`에 고정했다. 원래보고서 경로·당시SHA·collecting상태를 snapshot metadata에 보존했다. 이후 추가된 패치는 이 감사 범위 밖이다. 완료112쌍=6개주2020각16패치+Gorontalo2021 16패치로,256²×112=7,340,032픽셀을 모두 검사했다. `data/audits/esri-v1-alignment-20261016.json` 결과는 raster112pass/source112pass,fail0/error0/unverified0이다. 원본1024창 rawESRI/SCL에서 각256패치로 다시 계산했고 label/quality 픽셀 불일치는 모두0이었다. 주경계SHA가신규수집기에보존된 경우기록값과비교하고,구버전미보존은현재파일SHA근거라는한계를유지한다. 이는112패치의정합·약라벨원본재현이며1000패치충족·독립지상정답정확도·전체36연차셀완료를의미하지않는다.
