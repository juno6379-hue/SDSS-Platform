# 2026-10-16 연차 토지피복 공개 참조 조사

## 1. WorldCover 연도 복제를 대체하는 연차 참조

사용자 지시는2020~2025 해당 시기 참조를 확보하는 것이므로 WorldCover2021을2022~2025 정답으로 복제하지 않는다. 공개 Esri/Impact Observatory 연차 토지피복은 별도 모델이 Sentinel-2로 만든 연차 합성 분류지도다. 독립 지상정답이 아니며 실험 지표는 해당 참조 대비 일치도로 제한한다. 제품이 공개돼 있다는 사실과 인도네시아 해당 타일의 실제 바이트 확보를 구분한다.

## 2. 공식 출처 및 실제 접속 확인

|출처|확인 내용|상태|
|---|---|---|
|[Esri Spring2026 공지](https://www.esri.com/about/newsroom/arcnews/latest-land-cover-data-release-shows-more-change-over-time)|2025연차 자료 추가·CC BY4.0 다운로드 공지|원문 확인|
|[AWS 공식 공개자료 등록부](https://registry.opendata.aws/io-lulc/)|2017~2024, S3 io-10m-annual-lulc/us-west-2, 계정 없는 접근·CC BY4.0|원문 확인|
|[IO STAC collection](https://api.impactobservatory.com/stac-aws/collections/io-10m-annual-lulc)|실제JSON은2017~2024 설명,license필드proprietary이나 설명은CC BY4.0|HTTP200, 메타데이터 충돌 보존|
|[Esri 공식 Explorer](https://livingatlas.arcgis.com/landcoverexplorer/)|공식 앱 JS에서 Azure v003 다운로드 규칙 확인|HTML/JS 실제 확보|

IO STAC2024 검색은 Banten 부근 bbox105.9,-7.1,106.1,-6.9에서 `48M-2024`를 반환했다. 자산은 `https://io-10m-annual-lulc.s3.us-west-2.amazonaws.com/48M_2024.tif`, EPSG32748,10m,88550×66794다. 광역 원본 전체파일은 받지 않았다. 검색JSON은 `tmp/io-item-2024.json`, collection은 `tmp/io-collection.json`에 보존했다.

Esri 공식 JS `https://livingatlas.arcgis.com/landcoverexplorer/main.1160795a9572fe957c40.js`의 다운로드 상수는 `https://lulctimeseries.blob.core.windows.net/lulctimeseriesv003`이며 실제 규칙은 다음과 같다.

```text
2024 이상: /lc{year}/{tile}_{year}0101-{year}1231.tif
2023 이하: /lc{year}/{tile}_{year}0101-{year+1}0101.tif
예: /lc2025/48M_20250101-20251231.tif
```

위2025 예제 URL HEAD는 **HTTP200 / Content-Length123,008,438 / image/tiff / Last-Modified2026-04-22**를 반환했다. 이는2025원본 존재 확인이며 아직 픽셀 다운로드 완료가 아니다. 전체파일을 받는 대신 실제 AOI에 맞는 COG 부분 창을 수집해야 한다. IO STAC에2025가 반영되지 않은 상태를2025자료 부재로 오판하지 않는다. 네트워크 제한을 피해 다른 경로를 쓰는 목적이 아니라, 공식 제품 버전에 맞는 공개 다운로드 경로를 확인한 것이다.

조사 HTTP본문 보존량은 ExplorerHTML1,795 + JS3,664,524 + IOcollection1,941 + IO2024item7,468 = **3,675,728bytes**다. HEAD본문은0이며 헤더/TLS오버헤드를 포함한 총 트래픽 값은 아니다. 신규4GiB 수집 계획에서 조사 메타데이터 사용량으로 따로 기록한다.

## 3. 분류체계 계약

IO2024 STAC의 공식 `classification:classes` 및 `file:values`는 다음과 같다.2025 실제 원본의 제품/팔레트/클래스 검증은 수집 시 추가해야 한다.

|원본 값|제품 정의|기존9출력 체계로 검토할 ID|
|---:|---|---:|
|0|NoData|255 ignore|
|1|Water|0|
|2|Trees|1|
|4|Flooded vegetation|3|
|5|Crops|4|
|7|Built area|6|
|8|Bare ground|7|
|9|Snow/ice|8|
|10|Clouds|255 ignore|
|11|Rangeland|2, 별도 의미 명시 필요|

Rangeland는 기존 WorldCover 기반 grass와 같은 정의가 아니다. 새 실험은 모든 연도에 동일 Esri series를 사용하고, class2를 grass_or_shrub_rangeland 등으로 구분하여 target class 이름/매핑/출처를 manifest와 checkpoint에 저장해야 한다. 기존WC 모델의 클래스 이름을 소급 변경하지 않는다. WC와Esri 라벨을 같은 정답 의미로 무표시 혼합하지 않는다.

## 4. 사용 조건과 남은 검증

Esri 공식 제품 공지와 AWS 등록부는CC BY4.0을 명시하지만 IO collection의기계가독license필드는proprietary다. 이 충돌을 지우지 않고 공식 배포 공지·제품URL·접근일을 라이선스 근거로 보존하며 최종 배포 검토에 포함한다. 공급자 자체 제품 정확도 수치를 본 프로젝트 모델 정확도로 인용하지 않는다.

실제 수집에서는 연도별 파일명/출처, 원본 CRS·해상도, 해시, 해당 연도영상과의 정합, NoData/Cloud 제외, 원본crop과 변환을 보존한다. 연차 합성지도와 특정일 Sentinel영상 간 시기 불일치도 잠재 라벨 잡음으로 기록한다. 전문가 독립 참조가 없으면 실제 정확도 인수 및 운영 승인 단계는 계속 제한한다.
