# 183. 연차 균형과 부족 지역 우선 수집

2026-10-18 사용자 요청을 반영한다. 저장된 원본 수량과 최종 실험에 선택하는 자료 수량은 서로 다른 관리 대상이다. 원본 패치를 삭제하거나 같은 장면을 복제해 연도별 숫자를 맞추지 않는다. 기존 고정 train/val/test 분할과 동일 장면·지원 영상 겹침 차단도 유지한다.

## 현재 최소 계획과 균형의 의미

현재 6개 주×2020~2025년 36개 셀의 `cell_floor=28`은 **연도별 최소 확보 계획**이다. 각 셀을 정확히28개로 제한하는 상한이나 동일 수량 인수 기준이 아니다. 총 적격 목표1200, 유효80%·주내95%, 분할별 나지0.5%·256픽셀 이상 기여패치5개·최대 단일 클래스90% 기준도 별도로 남는다. 모든 셀에서28개를 선택하면1008개이므로 그 수만으로1200개 목표를 충족했다고 표시할 수 없다.

최종 연차 비교/학습 후보에서 같은 위치·계절·클래스 구성과 샘플 수를 어떻게 맞출지는 별도 고정 manifest/정책으로 검토한다. 현재 소단위는 그 정책이나 기존 QA·모델 승인 상태를 바꾸지 않는다. 적격 초과분은 원본·lineage에 보존한다. 신규 수집의 연차간 수량 차이는 UI에 그대로 표시한다.

## 명시 우선순위

사용자 요청에 따라 부족 셀 수집의 명시 순서는 **남동술라웨시 → 고론탈로 → 나머지 부족 지역**이다.177은 이 순서를 dry-run 계획SHA에 포함하고 실제 coordinator 진입점에서 동일 순서를 재검증한다. 이미 실행된 배치는 강제 중단하지 않으며 다음 배치부터 새 순서를 적용한다. 우선 지역에서 기존 신규 가용 창이 없으면 부족량을0으로 고치거나 기존 성공/실패 창을 새ID로 재실행하지 않고 차단 사유를 남긴다. 새로운 공간 후보는 경계·기존 영상·미정산 지원 영역의 겹침을 검토한 뒤 별도로 계획한다.

8차 완료 시점의 확정 부족은49개(남동26·고론탈로17·동자바6)다. 다른 개발 채팅이 먼저 시작한9차 동자바2020g02/g03의 종료/정산 후 현재 원본과 원장으로 우선 계획을 다시 고정한다. 해당 시점과 이후 추가분을 섞어49개가 계속 현재값이라고 하드코딩하지 않는다.
